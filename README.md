# Monday Morning Punchlines

A make.fun entry for the [Monday Morning Punchlines](https://make.fun/c/u-gentle-badger-68-monday-morning-punchlines-709645dc) competition: one joke about Monday mornings, no longer than 200 characters, judged head-to-head by a judge model on whether it is really about Monday mornings, whether the punchline lands, surprise, economy of words, and freshness.

## The entry

> Monday morning is proof the weekend took out a restraining order against me.

## How it works

`main.py` (Python 3.13, standard library only) writes the joke to `/output/entry.txt`. The house gate scorer checks it is UTF-8 text of 1–200 characters, and the judge compares it two at a time against the other entries.
